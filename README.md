# Pokémon API Workflow

Module 2, Files, APIs and Data Sources. Beginner Data Science exercise.

Workflow: **API -> JSON -> list of dictionaries -> pandas DataFrame -> CSV / Excel -> GitHub**

- `Pokemon_API_to_Excel_Allan_Canales.ipynb`: the notebook (outputs cleared, so the Git history stays tidy).
- `pokemon_data.csv` and `pokemon_data.xlsx`: the saved data for 5 Pokémon (pikachu, bulbasaur, charmander, squirtle, eevee) with name, height_dm, weight_hg, types, height_m and weight_kg.

Data comes from the free [PokéAPI](https://pokeapi.co/), which needs no API key.
